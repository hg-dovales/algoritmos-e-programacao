A **formalização da solução** consiste em transformar a ideia inicial de resolução de um problema em uma representação mais organizada e estruturada.

Um algoritmo pode ser representado de diferentes formas:

- **Descrição Narrativa:** utiliza linguagem comum para descrever os passos da solução;
- **Fluxograma:** utiliza símbolos gráficos para representar visualmente o fluxo do algoritmo;
- **Pseudocódigo:** utiliza uma escrita estruturada semelhante a uma linguagem de programação.

Cada representação possui suas próprias características, mas todas possuem o mesmo objetivo: **organizar e comunicar de maneira clara a lógica utilizada para resolver um problema antes de transformá-la em código.**
