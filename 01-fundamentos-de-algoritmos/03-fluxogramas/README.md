Um **fluxograma** é uma representação visual de um algoritmo, utilizada para mostrar de forma organizada a sequência das instruções e o fluxo de execução de uma solução.

Os principais elementos são:

- **Terminal (oval):** representa o início e o fim do algoritmo;
- **Processamento (retângulo):** representa uma ação, operação ou cálculo;
- **Linhas de fluxo (setas):** indicam a direção e a ordem em que as etapas são executadas.

O fluxograma facilita a visualização da lógica do algoritmo, permitindo compreender o caminho entre o **estado inicial** e o **estado final** antes da implementação em uma linguagem de programação.
