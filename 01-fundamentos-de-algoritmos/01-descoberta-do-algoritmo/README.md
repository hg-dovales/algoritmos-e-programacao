Um algoritmo é uma sequência finita e organizada de instruções utilizadas para resolver um problema.

Para construir bons algoritmos é importante:

- Compreender o problema;
- Identificar os dados necessários;
- Dividir o problema em etapas;
- Organizar as instruções corretamente;
- Evitar ambiguidades;
- Garantir que exista um término;
- Identificar entrada, processamento e saída.

A construção do algoritmo representa a lógica da solução antes de sua implementação em uma linguagem de programação.
